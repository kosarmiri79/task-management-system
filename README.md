# سیستم مدیریت وظایف (Task Management System)

## معرفی پروژه
سیستم مدیریت وظایف یک پروژه‌ی شخصی با هدف سازمان‌دهی فعالیت‌ها، پیگیری روند انجام وظایف و بهبود برنامه‌ریزی و مدیریت زمان است.

در این پروژه از Microsoft Excel برای ثبت و مدیریت وظایف و از مجموعه‌ای از پرامپت‌های هوش مصنوعی برای کمک به برنامه‌ریزی، سازمان‌دهی و کنترل کیفیت استفاده شده است.

## اهداف پروژه
- سازمان‌دهی وظایف در قالبی ساختاریافته
- تعیین اولویت و وضعیت هر وظیفه
- پیگیری روند پیشرفت فعالیت‌ها
- کمک به برنامه‌ریزی و مدیریت زمان
- استفاده از پرامپت‌های هوش مصنوعی برای پشتیبانی از مدیریت وظایف و کنترل کیفیت

## ابزارها و فناوری‌های استفاده‌شده
- **Microsoft Excel:** ثبت و پیگیری وظایف، ایجاد فهرست‌های کشویی، استفاده از فرمول‌ها و محاسبه‌ی میزان پیشرفت
- **Microsoft Word:** تهیه‌ی مستندات و راهنمای استفاده از پروژه
- **مهندسی پرامپت هوش مصنوعی:** طراحی پرامپت‌هایی برای کمک به برنامه‌ریزی، مدیریت وظایف و کنترل کیفیت

## امکانات اصلی پروژه
- ثبت و سازمان‌دهی وظایف
- انتخاب اولویت و وضعیت وظایف از طریق فهرست‌های کشویی
- محاسبه‌ی خودکار آمار وظایف
- نمایش میزان پیشرفت و درصد تکمیل وظایف
- ارائه‌ی مجموعه‌ای از پرامپت‌های هوش مصنوعی برای برنامه‌ریزی و کنترل کیفیت

## فایل‌های پروژه
- **فایل اکسل سیستم مدیریت وظایف:** فایل اصلی برای ثبت و پیگیری وظایف
- **راهنمای استفاده:** توضیحات مربوط به نحوه‌ی استفاده از سیستم
- **کتابخانه‌ی پرامپت‌های هوش مصنوعی:** مجموعه‌ای از پرامپت‌ها برای برنامه‌ریزی، مدیریت و کنترل کیفیت
- **معرفی پروژه:** توضیحات کلی درباره‌ی اهداف و ساختار پروژه

## مهارت‌های به‌کاررفته
- برنامه‌ریزی و سازمان‌دهی
- دقت و توجه به جزئیات
- مهارت‌های مقدماتی Microsoft Excel
- مستندسازی و مدیریت اطلاعات
- استفاده از هوش مصنوعی برای کمک به حل مسئله
- پیگیری فرایندها و ارزیابی میزان پیشرفت

## هدف از اجرای پروژه
این پروژه به‌عنوان یک نمونه‌کار شخصی با هدف نمایش مهارت‌های کاربردی در زمینه‌ی امور اداری، برنامه‌ریزی، سازمان‌دهی و استفاده از ابزارهای دیجیتال تهیه شده است.
